# Python 夹具生命周期

每轮 Vitest 由 global-setup.ts 顺序调用两个 Python 导出器，各生成一次当前代码对应的离线夹具。输出位于独立临时目录，通过 provide/inject 供测试读取，结束或生成失败时清理。

offlineFixture 每次重新解析 JSON，测试之间不共享可变对象；事件的全部前缀、v1/v2、导入和评价数据仍由本轮真实 Python 实现生成，没有使用旧静态快照替代。生成器有 60 秒进程上限，失败直接终止该轮，不跳过检查。

生成步骤属于测试准备，不占用各测试文件 10 秒的 beforeAll 钩子；npm test 仍执行原有全部断言。夹具使用模拟模型，不产生提供商调用或真实用户研究成绩。

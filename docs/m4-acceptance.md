## 当前用量与限制

2026-10-18 新 v2 采集 **5 次、4439 Token**；加上 2026-10-17 的 **6 次、4172 Token**（首次失败 552、旧 v1 A/B 3620），文档累计 **11 次、8611 Token**。每个 B 复用所属版本 A 的模型前缀，但本次实际续问的上下文 Token 仍以提供商 usage 为准；不再把继承步骤的整份 usage 另加一次。旧 M3 的 624 Token 属于另一日期的已发生调用，不混作文档新增。没有价格估算或逐笔扣费凭证，金额和实际账单均未知；不为等待账单重复付费。

旧 document-react:1 每响应只接受一个工具调用，拒绝多意图的语义保持。用户已确认的 document-react:2 使用独立图状态与提示，整批预检后逐工具串行执行，每项有独立观察点，最多 7 工具/8 模型；失败/取消保留在途事实并停止余项。提高 top_k 只保证该固定排序下返回更多元数据，不保证引用或答案正确；没有改写旧点，也没有重复抽取成功输出。

生产构建主入口约 524 kB（gzip 158 kB），仍有 Vite 500 kB 提示，加载性能尚未验收。尚未公开部署。M5 工具实操对照和真实用户研究均未开始。

## 重现无密钥阅读检查

```bash
npm --prefix web run build
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm --prefix web run check:references
```

检查器启动临时本机 FastAPI/生产静态构建，移除提供商密钥/模型变量，并禁止构造任何模型。仅测试脚本提供统计端点，普通 create_app 不增加该端点；检查结束清理临时服务/数据库。成功证据默认写 artifacts/m4-reference-browser-v2.json，截图在 artifacts/m4-real-reference-*.png。此命令不录制新的提供商请求。

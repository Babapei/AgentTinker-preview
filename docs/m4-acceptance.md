## 当前用量与限制

本轮新文档请求共 **6 次、4172 Token**：首轮 552，第二轮 A/B 合计 3620。第二轮 B 复用一个模型前缀，但本次实际续问的上下文 Token 仍以提供商 usage 为准；不再把继承步骤的整份 usage 另加一次。旧 M3 的 624 Token 属于另一日期的已发生调用，不混作本轮新增。没有价格估算或逐笔扣费凭证，金额和实际账单均未知；不为等待账单重复付费。

当前 document-react:1 是有界串行模板，每响应只接受一个工具调用。真实模型仍可能返回多个意图；现实现会在执行前拒绝并保存响应/用量。提高 top_k 只保证该固定排序下可返回更多元数据，不保证模型一定正确读取/作答。没有因为本次失败静默扩大并行或多工具执行范围，也没有重复抽取直到得到成功输出。

生产构建主入口约 523 kB（gzip 157 kB），仍有 Vite 500 kB 提示，加载性能尚未验收。尚未公开部署。M5 工具实操对照和真实用户研究均未开始。

## 重现无密钥阅读检查

```bash
npm --prefix web run build
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm --prefix web run check:references
```

检查器启动临时本机 FastAPI/生产静态构建，移除提供商密钥/模型变量，并禁止构造任何模型。仅测试脚本提供统计端点，普通 create_app 不增加该端点；检查结束清理临时服务/数据库。成功证据默认写 artifacts/m4-reference-browser.json，截图在 artifacts/m4-real-reference-*.png。此命令不录制新的提供商请求。

# M2 检查与回放验收

2026-10-16 · 对照 [架构路线](03-architecture-roadmap.md) 的既有 M2 条件：列表/图视图、节点详情、时间线、记录播放；实际事件驱动，播放不执行模型/工具，未知值准确呈现。

**结论：M2 完成，下一步 M3 首个实验闭环。** 后端 136 项、前端 40 项 Vitest、15 项实际 Chromium 集成通过；协议漂移、类型检查、生产构建、格式与 ruff 检查通过。固定安装脚本同时安装两端锁定依赖。入口见 [前端说明](web-inspector.md)。

| 完成条件 | 实现与验证证据 |
| --- | --- |
| 实际事件驱动 | 先读快照，再补齐 seq=1 起的持久化事实；EventLog 校验顺序、身份、状态与重试因果。实际 LangGraph synthetic 的失败/重试/取消每个事件前缀与 Python project_events 逐一相等；保留微秒时间精度，seq 仍是唯一事件顺序 |
| 列表、图与节点详情 | 列表和 React Flow 图共用当前投影视图；每个 Span 独立节点，父引用和执行器重试分别画边，不按时间猜依赖。点击、键盘选择、切换视图都检查同一实际步骤；继承/缺失父引用只画引用节点，不补造执行 |
| 事件时间线 | 只展示已应用的事件前缀，按 seq 排序，可筛选运行/调用/故障重试/检查点事件并检查原始 JSON；点击事件回到该前缀并定位关联步骤。终止原因来自当前已应用的状态事件 |
| 记录播放 | 上下事件、定位滑条、0.5×–4×、播放/暂停/到末尾停止、返回最新。纯前缀投影隐藏后续输入输出和用量；实际任务状态单独标识，播放边界固定，实时新增事实另计。真实后台模拟运行可在历史视图停留时继续到终态 |
| 播放不执行 | Chromium 测试在完整事件读完后捕获网络：选择、拖动、播放、暂停、恢复、返回最新均无额外 API 请求；原数据库 RunView 不变。执行器仅由测试驱动显式创建 native synthetic 运行，页面不发执行 POST |
| 断线补发与快照一致 | 实际本机流先返回持久化前缀、重复事实并关闭，浏览器从最后应用序号重新连接 FastAPI/SQLite，追到相同终态。持续缺口/跨 Run/冲突/快照不一致时保留可读快照并禁用播放；切换订阅不取消后台任务 |
| 未知值、来源与降级 | 部分用量保持总量未知并显示覆盖率，已知零保留；Decimal 费用字符串精确汇总同口径金额，估算与有凭证费用分开。路由 fixture 提供 imported 摘要、无 checkpoint/完整事件且无执行能力，验证仍可检查步骤/图，不伪造回放或分支 |
| 可读与可操作 | 实际键盘选择、390px 列表及图无页面横向溢出、减少动画；默认列表和图通过 axe WCAG 2 A/AA 自动检查。截图人工检查后调整图布局、长标题溢出与字色；不宣称完成跨浏览器或完整人工可访问性评审 |

验证源：[事件投影](../web/src/event-log.test.ts)、[SSE](../web/src/event-stream.test.ts)、[播放状态](../web/src/playback.test.ts)、[图关系](../web/src/execution-graph.test.ts)、[浏览器播放](../web/e2e/playback.spec.ts)、[实际订阅](../web/e2e/events.spec.ts)。跨语言期望由 [Python oracle](../scripts/export_event_fixtures.py) 在临时数据库生成，不手写一份预期业务结果。

本轮的实际集成是 Chromium、HTTP/SSE、SQLite、LangGraph 执行与跨语言重建；模型为明确 synthetic/offline，没有新付费调用。M0 的真实 DeepSeek 分支证据继续有效，实际账单仍独立待办。

当前是本地只读检查与历史播放；播放按事件等间隔步进，不重演真实请求耗时。播放位置只在当前页面内保存，刷新读取最新记录并保留 run/span 选择。正式导入接口、实验包和评价仍属 M4；测试用 imported 摘要不代表导入服务已实现。任务配置/运行控制、持久化 LangGraph saver、单变量 fork、A/B 对比与内嵌讲解按 M3 接入，当前 fork_from_checkpoint=false。UI 历史位置不能替代运行时 checkpoint。

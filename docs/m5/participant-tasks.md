# AgentTinker 首轮试用任务卡

请记录实际完成的步骤；遇到困难可以求助，未完成的部分也有价值。新建运行选择“模拟”，不需要填写模型密钥。任务耗时由观察者记录。

## T1：检查并处理一次工具超时

1. 新建工具超时实验并运行基线 A。
2. 找出失败步骤，说明它的输入、所属模型调用，以及失败发生在哪一层。
3. 从可用的工具前检查点创建 B，只修改一个你认为相关的受支持参数。
4. 检查 B 与 A 的配置、调用过程和输出；指出支持你判断的具体记录。
5. 说明是谁实施了变化、结果能证明什么，以及仍不能确定什么。

## T2：判断材料是否真正进入了回答

1. 新建文档实验并运行基线 A，检查模型、工具及最终输出。
2. 根据证据提出一个改动，从允许的检查点创建 B，只改一个受支持参数。
3. 分别检查搜索返回、正文读取和最终答案；查看规则评价。
4. 说明哪些判断来自直接记录，哪些还需要人工核实。请不要只给出一个总的“成功/失败”。

## T3：回看一份真实记录

观察者提供超时或文档参考 JSON。请导入并找到原 A/B，查看任务、来源与意见；播放一段历史，再返回最新并导出。

完成后说明：播放期间发生了什么、这个导入记录能否继续执行、B 的用量覆盖哪段调用，以及显示的费用是否足以证明实际扣费。

## 完成后

请说出最难理解的一处、一次容易误点的操作，以及你会怎样解释这次实验。观察者会记录你的原话；没有标准措辞要求。
